Tether manual binary installation (Arch Linux x86_64)

Prefer the .pkg.tar.zst package: sudo pacman -U tether-*.pkg.tar.zst

For the binary tarball, install runtime dependencies:
  sudo pacman -S qt6-base libsecret polkit nfs-utils cifs-utils smbclient

From the extracted directory, install the application and authorization helpers:
  sudo install -Dm755 usr/bin/tether /usr/bin/tether
  sudo install -Dm755 usr/lib/tether/tether-apply-helper /usr/lib/tether/tether-apply-helper
  sudo install -Dm755 usr/lib/tether/tether-control-helper /usr/lib/tether/tether-control-helper
  sudo install -Dm644 usr/share/applications/tether.desktop /usr/share/applications/tether.desktop
  sudo install -Dm644 usr/share/polkit-1/actions/org.tether.policy /usr/share/polkit-1/actions/org.tether.policy
  sudo install -Dm644 usr/share/icons/hicolor/512x512/apps/tether.png /usr/share/icons/hicolor/512x512/apps/tether.png
  sudo install -Dm644 usr/share/licenses/tether/LICENSE /usr/share/licenses/tether/LICENSE

Run tether as your normal desktop user, never with sudo.
Choose Add server to configure your first connection.
These binaries require Arch's system Qt libraries; they are not standalone.
Do not mix manual installation with a pacman-managed installation.
